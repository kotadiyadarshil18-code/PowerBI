# 📊 Sales & Performance Analytics Dashboard (Power BI)

## 📌 Project Overview  
This project focuses on **end-to-end Power BI development**, including:

- 🧩 Data Modeling (Star Schema)  
- 🧮 DAX Measures & Calculations  
- 📅 Time Intelligence  
- 📊 Interactive Dashboard Design  
- 🎛️ Advanced Filtering & Navigation  

👉 The goal is to transform raw data into **meaningful business insights** for better decision-making.

---

## 🗂️ Dataset Structure  

The project uses the following tables:

- `Date_Dim`  
- `Customer_Dim`  
- `Product_Dim`  
- `Region_Dim`  
- `Sales_Fact`  
- `Returns_Fact`  

---

## 🧩 Data Modeling  

- Built **Fact & Dimension tables**  
- Established relationships using:  
  - 🔑 Primary Keys (PK)  
  - 🔗 Foreign Keys (FK)  
- Followed **Star Schema Design**  

✅ Ensured:  
- Clean structure  
- Consistent naming conventions  

---

## 🧮 DAX Measures  

Created important measures using:

- `CALCULATE`  
- `FILTER`  
- `ALL`  
- `SUMX`  
- `COUNTX`  
- `AVERAGEX`  

### 📌 Key Measures:
- Total Sales  
- Total Profit  
- Total Returns  
- Average Sales  
- Performance Metrics  

---

## 🧠 Calculated Columns  

- Profit Margin Classification  
- Customer Full Name (First + Last)  
- Year-Month Formatting  

---

## 📅 Time Intelligence  

Implemented:

- 📈 YOY (Year-over-Year) Growth  
- 📊 MOM (Month-over-Month) Growth  
- 📆 YTD (Year-to-Date) Sales & Returns  

🔍 Also identified **seasonal trends**
