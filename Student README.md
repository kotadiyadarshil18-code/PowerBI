# 📊 Student Performance Dashboard (Power BI Project)

## 🎯 Theme
- Modern, clean, and professional
- Minimal + infographic style
- Soft gradient colors (blue, green, purple)
- Use icons and visual elements
- Balanced spacing (not text-heavy)

---

## 🟦 Slide 1: Title Slide
**Title:** Student Performance Dashboard  
**Subtitle:** Data Modeling, DAX & Visualization Project  

**Description:**  
This project focuses on analyzing student performance using Power BI with proper data modeling, DAX calculations, and interactive dashboards.

---

## 🟦 Slide 2: Data Modeling & Cleaning

**Points:**
- Load all datasets and create relationships  
- Clean column names and correct data types  
- Replace null or missing values where necessary  

**Explanation:**  
In this step, all datasets are loaded and relationships are created between tables.  
Data cleaning is performed by fixing column names, correcting data types, and handling missing values.

---

## 🟦 Slide 3: DAX Measures

**Calculated Fields:**
- % Score = Score / MaxScore  
- Average Score per Subject  
- Attendance %  
- Behavior Count per Type  
- Performance Category (High / Medium / Low using SWITCH or IF)  

**Explanation:**  
DAX measures are created to perform calculations and derive meaningful insights.  
Performance categories help classify students based on their scores.

---

## 🟦 Slide 4: Visualizations

**Charts:**
- Bar Chart: Average scores by Subject and Class  
- Line Chart: Performance trend by Term  
- Donut Chart: Behavior distribution  
- Table: Student-wise scores with conditional formatting  
  - Green (>80%)  
  - Red (<40%)  

**Cards:**
- Total Students  
- Average Attendance  
- Average Score  

**Explanation:**  
Visualizations help in understanding trends, comparisons, and performance metrics effectively.

---

## 🟦 Slide 5: Interactivity

**Features:**
- Slicers (Class, Section, Subject, Term)  
- Drillthrough (Student Profile Page)  
- Tooltips (Mini charts / metrics)  
- Bookmarks (Academic ↔ Behavioral navigation)  

**Explanation:**  
Interactivity allows users to explore data dynamically and gain deeper insights.
