# 📊 Sales Data Model – Power BI Project

## 📌 Project Overview

This project focuses on **data modeling and analysis in Power BI** using a structured dataset.

* Focus on DAX concepts, relationships, and matrix-based reporting
* No use of charts or other visuals
* All outputs are displayed using **Matrix Visual only**

---

## 📁 Required Dataset Tables

The following tables are used in this project:

* Sales_Fact
* Returns_Fact
* Customer_Dim
* Product_Dim
* Date_Dim
* Region_Dim

---

## 🧮 Calculated Columns

The project includes creation of important calculated columns:

* Profit column in Sales_Fact (to calculate earnings)
* Return Flag column (to identify returned items)
* Customer Full Name column (combining first and last name)

---

## 📊 Measures

Key business measures are created for analysis:

* Total Sales
* Total Cost
* Total Profit
* Return Rate (percentage of returned items)
* Average Sale per Transaction

---

## 🎯 Quick Measures

Quick measures are used to analyze trends:

* Year-over-Year Sales Growth
* Difference between Current Month and Previous Month Sales

---

## 📦 Measure Management

* A dedicated **Measure Table** is created
* All DAX measures are organized in one place for better structure

---

## 🔍 Filter Context & Behavior

Matrix visual is used to understand filtering behavior:

* Comparison of sales with and without filters
* Usage of filtering logic to control data visibility

---

## ⚙️ DAX Functions & Concepts

The project uses core DAX concepts:

* Aggregation functions (sum, average, max)
* Logical conditions (if, switch)
* Text operations (combine and format text)
* Date functions (year, month, end of month)

---

## 🔗 Relationships

* Data model is built using **star schema**
* Relationships are created between fact and dimension tables
* Related data is used across tables for analysis

---

## ⏳ Time Intelligence

Time-based analysis is performed using:

* Year-to-date calculations
* Previous year comparison
* Period-based analysis

Used for:

* Monthly performance tracking
* Yearly comparison
* Running totals

---

## 🧠 Additional Scenarios

Advanced logic is applied:

* Sales categorized into Low, Medium, High
* Use of iterative calculations for deeper analysis

---

## 📤 Output Requirement

All results are displayed using **Matrix Visual only**

### Grouping:

* Region
* Month
* Product Category
* Customer Segment

❌ No other visuals are used
